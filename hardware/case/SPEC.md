## Fusion access and gotchas (read carefully)
You drive Fusion through the MCP tool `mcp__Autodesk_Fusion__fusion_mcp_execute` (featureType "script", object {"script": "<python>"}) — the script must define `def run(_context: str):`; prints are returned; API units are cm (mm × 0.1). `mcp__Autodesk_Fusion__fusion_mcp_read` can search/list documents and screenshot. Gotchas learned this week: (1) if a script raises, its model changes roll back — put asserts at the end, no try/except around modeling; (2) Jake keeps several documents open and the ACTIVE document can switch under you — every script must first find and `activate()` the intended document by name and assert `app.activeDocument.name`; (3) `offsetFacesFeatures.createInput(list_of_faces, ValueInput)` takes a Python list; OffsetFaces propagates along tangent chains; (4) `root.constructionPoints.add` raises "Environment is not supported" — use a sketch point; (5) extrude taper sign flips between single-loop and ring profiles — build tapered cones as separate single-loop bodies and boolean them; (6) `occurrence.bRepBodies` gives world-space geometry, `occurrence.component.bRepBodies` does not; (7) screenshots: `viewport.saveAsImageFile(path, w, h)` with an Orthographic camera and `cam.viewExtents` (perspective + extents raises); (8) chamfer edges may be split into several arcs — collect all matching edges. Verification pattern: point-containment scans (`body.pointContainment(Point3D)` in {PointInside, PointOn}) along a line at 0.02–0.05 mm steps to find solid spans; interference via `design.createInterferenceInput(ObjectCollection)` / `analyzeInterference`.
Never modify or save Jake's existing documents ("Firefly V2 ..." — the reference; "KandiWooks Logo"; the board models). The generator creates a NEW document each run: `app.documents.add(adsk.core.DocumentTypes.FusionDesignDocumentType)`, names it "Firefly Case Gen <timestamp>", builds everything, and leaves it open unsaved. To run the generator from disk inside Fusion, send a tiny wrapper script: `import runpy; g = runpy.run_path('/private/tmp/claude-501/case-generator/hardware/case/firefly_case.py'); g['run'](_context)` — so the real code lives in the repo file and Fusion executes it.
