# Firefly T9 curated vocabulary — the high-priority layer over the general-English base.
#
# Curated by hand for a FESTIVAL MESSENGER: modern texting words, abbreviations,
# reactions, raver/EDM/festival slang, and coordination/logistics terms — the
# stuff a Gutenberg corpus can't cover ("tbh", "wtf", "lol", "k"). One token per
# line, roughly ordered most-common-first within sections; the gen script ranks
# these ABOVE the general-English corpus so they surface first in T9.
#
# License: authored by the Firefly project (GPL-3.0). Plain, common words +
# public slang — no third-party corpus, no licensing encumbrance.
#
# Editorial choices (deliberate, documented so they're a decision not an accident):
#  - Alcohol is normal festival vocab and included (beer, drinks). HARD DRUG slang
#    is intentionally OUT of the shipped default (brand/trademark safety on a
#    named, trademarked project); anyone can add a local supplement.
#  - Lowercase only; the composer decides casing. Apostrophes dropped (T9 keypad
#    has no apostrophe): "dont", "im", "youre", "cant" as people actually type them.
